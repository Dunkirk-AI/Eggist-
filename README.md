# Eggist-
EGGIST（先有蛋）是一个开源的可视化 AI 协作工作台，致力于解决传统 Chatbox 对话遗失、思路难以回顾、协作经验难以复用等问题。  通过 快速发散，快速验证，快速找回。  我们希望通过可自由拖动、编辑的可视化白板，让用户对一个 IDEA 进行不同方向的发散与调研，利用多 Agent 交叉验证、竞品分析与盈利分析，实现快速细分发现与验证。  同时，通过思维导图、对话分支和 Markdown 式文件整理，实现先前调研思路的快速找回。  我们不追求最强大的 Agent、最多的 Skill 或最便宜的 Token，而是希望打造一个更加好玩、自由、适合项目前期工作的开源 AI 唠嗑平台。
