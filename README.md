# 先有蛋 Eggist 项目简介
EGGIST（先有蛋）是一个开源的可视化 AI 协作工作台，致力于解决传统 Chatbox 对话遗失、思路难以回顾、协作经验难以复用等问题。  

**核心概念 快速发散，快速验证，快速找回**

我们希望通过可自由拖动、编辑的可视化白板，让用户对一个 IDEA 进行不同方向的发散与调研，利用多 Agent 交叉验证、竞品分析与盈利分析，实现快速细分发现与验证。  同时，通过思维导图、对话分支和 Markdown 式文件整理，实现先前调研思路的快速找回。  我们不追求最强大的 Agent、最多的 Skill 或最便宜的 Token，而是希望打造一个更加好玩、自由、适合项目前期工作的开源 AI 唠嗑平台。

# 需求文档 \- 先有蛋 EGGIST

# WHY \- 为什么有这个产品

## 痛点

1. **对话遗失！** 对话窗口太多太长，既找不到AI产出的一些内容，也找不到自己当时的提问思路

2. **无聊的CHATBOX！** CHATBOX 非常棒，但是在AI与人协作的时代，天然不适合保存产出与回顾思路

3. **经验低价值！** 与AI的协作模式，工作流程，提示词经验，难以保存导出为可视化的skill

4. **隐私？** 所有对话数据，关键提问，都被存储在云端，部分想法，思路工作流往往被轻易曝光

5. **一个AI**！像是GPT这种产品，往往只有一个AI可以使用



## 现有方案

1. **可视化设计AI**
经典案例有Lovart，flowith，其大致思路主要就是云端版的confulUI，主要目的是将素材引用，图像制作变为可视化的工作流
我们与他们的**区别**在于，他们的产品服务于设计之后的解决问题，我们的产品服务于发现问题，同时他们以图片与视频生成模型为主，我们则以文字对话模型为主

2. **本地中转站**
经典案例有CherryStudio，让你可以随时调用不同AI，并且开源，安全，可以本地化，并且甚至可以看到对话分支
我们与他们的**区别**在于，可视化内容的交互模式完全不同，并提供了更高的自由度

3. **文档整理AI**
经典案例有heptabase，拥有非常不错的知识梳理功能
我们与他们的**区别**在于，heptabase的功能在于已有文档整理，而我们的功能则在于，通过AI对话发现新的内容，产出新的文档，他们在于已有文档的研究，我们在于IDEA的快速发散与快速验证



## 需求定义

我们需要满足的是对于AI对话中的，可视化需求，归档整理需求与找回需求，并满足用户对可视化界面的拖动与编辑需求。

总的来说，我们将提供给个人工作者一种基于现在产品，但是更适合 **项目前期工作的交互产品**



# WAHT \- 这是一个什么样子的产品

## 价值主张

**快速发散，快速验证，快速找回**

让产品能够快速的对一个IDEA进行不同的发散与调研，多agent同时调研补齐现有市场情况，**快速进行细分发现**，并实现不同IDEA之间的快速比对，竞品分析，与盈利分析以求**快速验证，同时通过更棒的思维导图，**markdown式文件整理，以求进行**先前调研思路的快速找回。**



**更加好玩的开源 AI 唠嗑平台**

本产品不求能够拥有最恐怖的agent能力，最多的skill或者最便宜的token，关键是通过可视化界面，让用户发现并尝试更多有意思的agent步骤，从而更愿意转发平台，玩转agent。同时给予用户高度的自由度，让他们可以切换里面大量有意思的功能。

## 主要功能

1. 多个AI Agent 调研/工作
连入不同API与不同AI进行聊天，随时切换模型，用不同模型验证IDEA，并且可以调用不同skill进行系列多样化的自动操作

2. 可视化界面（详情见实际页面）
拥有一套更棒的可视化界面，可以将你的对话通过类似思维导图的方式进行记录
可以回到之前的节点随时创立新的分支，新的任务
简化卡片，保留用户问题和AI回答的关键内容
框选系列卡片，让其他AI分析这个问题是否正确
\.\.\.\.\.\.\. 

3. 归档与搜索（详情见实际页面）
将多段对话整理为一个项目，自由在项目中进行系列编辑

4. AI 发送表情包与各类内容
AI在work时将弹出一个对话框，展示各种有意思的表情包

5. 本地化储存
